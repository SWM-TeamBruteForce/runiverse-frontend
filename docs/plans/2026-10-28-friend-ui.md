# 친구 맺기 UI 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 러너끼리 친구 요청을 보내고 수락해 친구가 되는 화면을 만든다.

**Architecture:** `lib/features/friend/`를 새로 만들고 `domain → data →
presentation` 세 층으로 쌓는다. 관계 enum과 묶기는 순수 계산이라 먼저 못
박고, 그 위에 repository·provider·화면을 얹는다. 프로필 탭은 줄 하나를 더하는
것으로 끝난다.

**Tech Stack:** Flutter + fvm · Riverpod 3 `Notifier`/`NotifierProvider` ·
dio · go_router · Lucide 아이콘

**Spec:** `docs/specs/2026-10-28-friend-design.md`

## Global Constraints

- 모든 flutter/dart 명령 앞에 `fvm` — 이 저장소에서는 `./.fvm/flutter_sdk/bin/flutter.bat`
- 의존 방향 `presentation → domain ← data`. domain은 순수 Dart만.
- 다른 feature의 **화면·위젯**은 import하지 않는다. provider는 `friend → profile` 한 방향만 허용(설계 §9-2).
- 색·치수·타이포·문자열은 전부 토큰 — `context.appColorsV2` `AppSpacing` `AppRadius` `AppTypographyV2` `AppStrings`. `core/theme/tokens/` 밖에서 `Color(0x...)` 금지.
- 아이콘은 Lucide 또는 `assets/icons/` SVG만. `Icons.*` 금지.
- UI 텍스트는 한국어. 이 기능에서는 **"친구"라고 쓴다**(설계 §1).
- `StateProvider`/`StateNotifierProvider` 금지.
- 화면은 loading / data / error 3분기를 모두 처리한다.
- 커밋은 `<이모지> <Type>: <설명>` — `📍 Feat` `🔨 Fix` `✅ Test` 등. AI 공동 작성자 표기 금지.
- 한 PR 20파일·500줄. **이 계획은 넘는다** — 아래 "PR을 어떻게 끊나" 참고.

## PR을 어떻게 끊나

파일이 25개 남짓이라 한 PR에 다 담기지 않는다. 같은 브랜치에서 둘로 낸다.

| PR | 범위 | 왜 여기서 끊나 |
|---|---|---|
| 1 | Task 0 — 어휘 통일 | 다른 작업과 겹치는 파일이 없고, 되돌리기도 쉽다. 먼저 머지해야 뒤 작업이 "친구"를 쓴다 |
| 2 | Task 1~7 — 친구 기능과 진입점 | 여기까지로 **친구를 맺을 수 있다** |
| 3 | Task 8 — 타인 프로필 | 목록 행을 누를 곳이 생긴다 |

2와 3이 합쳐 20파일 안에 들면 하나로 낸다. 실제 크기를 보고 정한다.

## Review Focus

테스트가 짚지 않는데 사람을 물 가능성이 높은 것들. 각 줄의 테스트는 해당
Task에 넣어 두었다.

1. **`POST /friend-request`가 `201`이 아니라 `200` + `FRIEND`로 온다** — 상대가 먼저 요청해 둔 경우. 상태 코드로 분기하면 "요청 취소" 버튼이 떠야 할 자리에 엉뚱한 것이 선다. (Task 4)
2. **프로필 API가 같은 뜻을 다른 말로 준다** — `friendStatus: ACCEPTED`를 못 읽으면 친구인 사람에게 "친구 요청" 버튼이 뜬다. (Task 1)
3. **취소·거절·삭제는 멱등이 아니다** — 두 번 누르면 `404`. 느린 네트워크에서 연타가 실제로 일어난다. (Task 5)
4. **검색 두 번째 페이지가 앞 묶음에 끼어든다** — 묶음 안에서 서버 순서를 안 지키면 이미 그려진 행 사이로 들어가 목록이 튄다. (Task 2)
5. **친구 화면에서 관계를 바꾸고 돌아오면 프로필 숫자가 옛날 값이다** — push된 라우트라 저절로 갱신되지 않는다. (Task 7)
