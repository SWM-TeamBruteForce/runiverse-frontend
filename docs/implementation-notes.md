## 1. 문서 — 어느 것이 정본인가

### 1-1. 충돌 시 우선순위

> **범위·구조 충돌** → `IA` > `기능명세서` > `와이어프레임`
> **비주얼·토큰 충돌** → `디자인 시스템` > `Figma` > `와이어프레임`

Figma에도 디자인 시스템이 있다(파일 키 `Ds2URinGrgXo43wC5OFQ8x`). **Figma는 정본이 아니라 구현체다** — 표현할 수 없어 대역을 쓴 곳이 있다(폰트가 대표적). **Figma에서 잰 픽셀값이 문서와 다르면 문서가 이긴다.**

### 1-2. ⚠️ 와이어프레임이 낡은 화면 3개

와이어프레임은 **컬러 시스템이 기획되기 전에** 작성됐다. 아래 3개는 와이어프레임만 보고 만들면 **틀린 화면이 나온다.**

| 화면 | 와이어프레임(낡음) | 실제로 만들 것 |
|---|---|---|
| S15 종료 요약 | 색 리빌 단계 없음 | **색 리빌 연출 포함** |
| S20 프로필 | 잔디 히트맵 + 뱃지 | **시그니처 오라 + 컬러 컬렉션** |
| S21 기록 | 일반 캘린더 | **색 모자이크 캘린더** |

## 2. 매칭 — MVP 범위

**MVP의 매칭은 예약 매칭이다.** 30분 슬롯 × 거리(3/5/10km) × 페이스 수준으로 2~4명 자동 매칭.

- 실시간 즉시 매칭은 **1차 확장**이다. 지금 만들지 않는다.
- **지역은 매칭 조건이 아니다** (원격 매칭이므로).
- 조건은 프리셋으로만. 자유 입력을 허용하면 조합이 흩어져 매칭 성사율이 떨어진다.
  <br>⚠️ *이 프리셋 규칙은 기획 문서에서 근거를 확인하지 못했다. 기능명세서와 대조가 필요하다.*

## 3. 색 시스템 — 가장 틀리기 쉬운 부분

### 3-1. 색은 feature 3개에 걸친다

S15 리빌 · S20 오라 · S21 모자이크. 의존 규칙에 예외를 만들지 말고 **역할로 나눈다.**

| 위치 | 역할 |
|---|---|
| `core/widgets/color/` | `Color`를 **파라미터로 받아** 그리기만 하는 순수 표현 위젯 |
| `features/color/` | 지표→색 매핑, 팔레트, 컬렉션 같은 도메인 로직과 전용 화면 |

### 3-2. 러닝 색은 테마가 아니라 데이터다

한 화면에 여러 개가 동시에 뜬다(모자이크 캘린더는 30개). **ThemeExtension에 넣지 말고 위젯 파라미터로 전달한다.**

### 3-3. 글로우와 elevation은 역할이 다르다 — 섞지 않는다

- `glow.*` = 러닝 색이 발광하는 표현. `elevation.*` = 면의 높이 위계를 나타내는 중립 그림자.
- `glow`는 반드시 **색을 인자로 받는 형태**(`glow.md(runColor)`)로 만들어, 앱 크롬에 실수로 쓸 수 없게 한다.
- `Material(elevation:)` 단축 경로가 둘을 섞기 가장 쉬운 지점이다.

### 3-4. 글로우를 텍스트 뒤에 깔지 않는다

러닝 중 수치는 대비 **7:1**을 만족해야 하는데, 숫자 뒤 색 번짐이 이를 무너뜨린다.

### 3-5. 색만으로 정보를 전달하지 않는다

컬렉션 슬롯엔 범주·shade 라벨, 모자이크 셀엔 날짜를 병기한다. (색맹 대응)

## 4. 러닝 화면 (S11~S13)

- 터치 타깃 **56px** (그 외 화면은 44px)
- 파괴적 액션은 탭이 아니라 **hold-to-end(2초) 또는 2단계 확인**으로만
- ⚠️ **`FontFeature.tabularFigures()`는 폰트가 `tnum`을 지원하지 않으면 Flutter가 조용히 무시한다.** 에러도 경고도 없다.
  <br>→ **2026-07-31 확인 완료.** Pretendard OTF 바이너리에서 `tnum` 태그 존재를 확인했다. 다시 확인할 필요 없다. 단, 폰트 파일을 교체하면 재확인한다.

## 5. Riverpod / 라우팅 함정

### 5-1. 숨은 탭의 provider는 실제로 dispose된다

매칭 상태를 홈 화면 안에 두면 **탭을 옮기는 순간 타이머와 WebSocket 구독이 끊긴다.**
→ 전역 매칭 상태는 `keepAlive`를 명시하고, **글로벌 스티키 배너와 홈 히어로가 같은 하나의 provider를 구독**한다.

### 5-2. `redirect` 안에서 `ref.watch`를 쓰지 않는다

무한 리빌드가 난다. `refreshListenable`을 쓴다.

### 5-3. 그 외

- 5탭은 `StatefulShellRoute`로 구성해 탭 전환 시 스크롤·상태를 보존한다.
- 글로벌 매칭 스티키 배너는 **Shell 레이어에 1개만.** 화면마다 복붙 금지.
- 알림 딥링크는 매핑 테이블 1곳으로 관리하고, 대상이 없으면 홈으로 폴백한다.
- **UI는 상태를 계산하지 않는다.** 페이스 환산, 상위 % 산출, 히스테리시스 판정은 `domain/`이나 provider에 둔다.
- Stream 구독(GPS, WebSocket)은 반드시 `ref.onDispose`에서 취소한다.
- 상태 전체를 watch하지 말고 **필요한 필드만 `select`** 한다. 러닝 화면은 초당 여러 번 갱신되므로 전체 watch는 화면 전체 리빌드가 된다.

## 7. 함께 고쳐야 하는 짝

아래가 바뀌면 **같은 커밋에서** 짝을 맞춘다. 안 맞추면 다음 사람 PC에서 빌드가 깨진다.

| 바뀐 것 | 같이 고칠 곳 |
|---|---|
| `.fvmrc` 버전 | `.vscode/settings.json`의 `dart.flutterSdkPath` (`fvm use <버전>`이 대신 갱신해 주기도 한다) |
| `main.dart` 교체 | `test/widget_test.dart` |
| `assets/` 파일 추가 | `pubspec.yaml`의 `assets:` / `fonts:` 블록 (선언 없이는 번들되지 않는다) |
| 앱 식별자(org) | `android/app/build.gradle.kts`와 iOS `Runner.xcodeproj/project.pbxproj` **양쪽** |
| `pubspec.yaml` 의존성 | 이 문서 / `CLAUDE.md`의 Tech Stack |

`lib/` 밖에서 앱이 쓰는 것은 `assets/fonts/`(Pretendard) 하나다.

## 8. 기타 제약

- 피드 공개 범위(팔로워/전체/나만)는 **UI만 만들고 서버 필터를 안 걸면 안 된다.**
- 소셜 로그인 시크릿은 **서버 보관이 원칙.** 클라이언트에 두지 않는다.
- 인증 순서: 이메일 인증 기반 로컬 로그인 → 소셜(구글·카카오).
- **기술 리스크 1순위는 백그라운드 GPS 추적과 다중 사용자 실시간 동기화다.** 다른 화면보다 먼저 프로토타입으로 검증한다.
